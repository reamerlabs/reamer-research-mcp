# Reamer Research skill for Claude Code

A Claude Code plugin with one skill, `reamer-research`: how to write a
[Reamer Research](https://reamerlabs.com/products/reamer-research) strategy,
backtest it with your costs, read its trades, run Monte Carlo and open visual
trade diagnostics, plus porting guides for Backtrader, NautilusTrader and
QuantConnect LEAN.

The skill works with the engine from PyPI
(`pip install reamer-research`, https://pypi.org/project/reamer-research/). The `reamer-research` plugin in the root of
this repository adds the Reamer Research MCP server as well; see
https://reamerlabs.com/docs/research-mcp
